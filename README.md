# iobox para Windows

Instalador do aplicativo iobox: pedidos com alerta sonoro, impressão automática das comandas e WhatsApp da loja.

**[Baixar o iobox para Windows](https://github.com/Caizencompany/iobox-windows/raw/main/iobox-Setup.exe)**

- Versão 1.3.4 · Windows 10 e 11
- O serviço de impressão já vem junto
- Use o mesmo login do painel iobox

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
